## racknerd vs contabo 常见问题

**RackNerd 的年付特价第二年续费会涨价吗？**
不会。特价套餐按下单时的价格锁定续费，这是它和其他便宜VPS商家最不一样的地方之一。

**Contabo 的无限流量真的无限吗？**
条款写的是每月 32 TB 出站流量，连续 10 天平均出站超过 100 Mbit/s 会被限速到 100 Mbit/s。博客和小型应用基本用不完这个额度，做视频代理或大文件分发就要心里有数。

**这两家能跑生产业务吗？**
可以跑对可用性不敏感的服务，但不建议放收入依赖型业务。第三方 30 天监控里，Contabo 高峰期响应明显变慢，RackNerd 入门款出现过两次约 20 分钟的失联。真正的生产环境请看更高价位的产品线。

**RackNerd 支持 Windows 吗？**
支持，两家都提供 Windows VPS。注意 Contabo 的 Windows 授权要额外付费加购，算预算时别漏掉。
